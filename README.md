# AI News Telegram Bot

Готовый бесплатный автопубликатор новостей и практических материалов об ИИ.

Он раз в четыре часа:

1. читает официальные RSS-ленты;
2. оставляет только свежие материалы об ИИ, ботах и автоматизации;
3. удаляет повторы;
4. с помощью бесплатного лимита Gemini готовит короткий пост на русском;
5. публикует лучший материал и чередует новости с гайдами;
6. сохраняет список обработанных ссылок, чтобы не публиковать их повторно.

Если Gemini временно недоступен, бот не ломается: он публикует аккуратную сокращённую версию текста из RSS. Для русскоязычных постов рекомендуется добавить бесплатный ключ Gemini.

## Что нужно создать

- Telegram-канал.
- Telegram-бота через [@BotFather](https://t.me/BotFather).
- Бесплатный аккаунт GitHub.
- Бесплатный ключ в [Google AI Studio](https://aistudio.google.com/app/apikey).

Ключи нельзя вставлять в файлы проекта или отправлять в переписку.

## Подключение Telegram

1. Откройте `@BotFather`, отправьте `/newbot` и сохраните выданный токен.
2. Добавьте бота в администраторы канала.
3. Разрешите ему публиковать сообщения.
4. Если канал публичный, его идентификатор — адрес вида `@my_ai_channel`.
5. Для приватного канала потребуется числовой идентификатор вида `-1001234567890`.

## Запуск бесплатно на GitHub

1. Создайте новый приватный репозиторий GitHub и загрузите в него все файлы этого проекта.
2. Откройте в репозитории **Settings → Secrets and variables → Actions**.
3. Создайте секреты:

   - `TELEGRAM_BOT_TOKEN` — токен от BotFather;
   - `TELEGRAM_CHAT_ID` — `@имя_канала` или числовой ID;
   - `GEMINI_API_KEY` — ключ Google AI Studio.

4. Откройте вкладку **Actions**, выберите **Publish AI news** и нажмите **Run workflow**.
5. Первый ручной запуск проверит настройки и опубликует максимум один свежий материал. Затем всё будет работать автоматически.

GitHub может попросить разрешить Actions в настройках репозитория. Процессу также нужно право **Read and write permissions**, потому что он обновляет файл `data/state.json` со списком уже обработанных публикаций.

## Безопасная проверка без публикации

Локально можно проверить отбор материалов:

```bash
python -m pip install -r requirements.txt
DRY_RUN=true python bot.py
```

В этом режиме сообщения выводятся в журнал и не отправляются в Telegram.

## Настройки

Все параметры необязательны и задаются как GitHub Actions variables или переменные окружения:

| Параметр | Значение по умолчанию | Что меняет |
|---|---:|---|
| `MAX_POSTS` | `1` | Максимум постов за один запуск |
| `FRESH_HOURS` | `48` | Насколько старой может быть публикация |
| `MIN_SCORE` | `6.0` | Минимальная оценка полезности от Gemini |
| `GEMINI_MODEL` | `gemini-2.5-flash-lite` | Модель для подготовки русского текста |
| `DRY_RUN` | `false` | Проверка без отправки в Telegram |

Источники находятся в `sources.json`. У каждого есть тип `news`, `guide` или `auto`. Можно отключить источник полем `"enabled": false`.

## Как формируется публикация

Каждый пост содержит:

- короткий заголовок;
- только факты, присутствующие в исходном материале;
- объяснение практической пользы;
- имя и прямую ссылку на первоисточник;
- рубрику и несколько хештегов.

Материалы с инструкциями публикуются как обзор гайда со ссылкой на полный оригинал. Бот не придумывает команды, которых нет в источнике.

## Ограничения бесплатного варианта

- Бесплатные квоты и доступность внешних сервисов могут меняться.
- Расписание GitHub Actions иногда запускается с задержкой.
- В бесплатном Gemini-тарифе отправленный текст может использоваться Google для улучшения продуктов; бот передаёт только общедоступные заголовки и краткие описания статей.
- Полностью автоматический канал всё равно стоит просматривать хотя бы раз в несколько дней.
